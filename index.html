Technology

HTML

HTML is the foundation of every website. I use it to create clear and well-structured layouts that define how each section of a page should look and function. Learning HTML has helped me understand how websites are built from the ground up, and it’s the first step in turning my ideas into interactive web pages.

CSS

CSS allows me to turn plain web structures into beautiful and responsive designs. I use it to add colors, adjust spacing, and create layouts that look great on all devices. Through CSS, I’ve learned how to build modern interfaces that are both visually appealing and easy to use. It’s an essential tool for expressing creativity and improving the user experience.

Tailwind CSS

Tailwind CSS helps me design faster by using utility classes to style elements directly in the markup. It allows me to create responsive, modern layouts without writing long custom CSS files. I love how it keeps my workflow clean and organized while encouraging consistency in design. As a beginner, Tailwind CSS has taught me how to structure interfaces efficiently and focus more on creativity instead of repetitive styling.
